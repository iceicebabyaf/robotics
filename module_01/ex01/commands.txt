== 1 ==
Название: lsof
Описание: отображает список открытых файлов и сетевых соединений
Синтаксис: lsof [опции] [файл|путь|порт]
Пример: lsof -i:8000
Вывод процессов, использующих 8000 порт
Примечание: без опций выводит все открытые файлы и процессов (-i - для ограничения вывода только сетевых соединений)

== 2 ==
Название: ss
Описание: отображает сокеты и сетевые соединения
Синтаксис: ss [опции]
Пример: ss -ltnp
Примечание: l(только прослушиваемые), t(TCP), n(показывать номера портов, а не имена сервисов), p(процессы, держащие порты)

== 3 ==
Название: ps
Описание: отображает список текущих процессов в системе
Синтаксис: ps [опции]
Пример: ps aux (a-все пользователи, u-подробная инфа с владельцем, x-включая процессы не из терминала)
Примечание: часто может пригодится добавка `| grep _` - для конкретного процесса

== 4 ==
Название: kill
Описание: завершает процесс
Синтаксис: kill [опции] <PID>
Пример: kill -9 3555
Примечание: `-9` - немедленное завершение процесса (небезопасно, не дает корректно очистить ресы)

== 5 ==
Название: df
Описание: отображает информацию о свободном и занятом месте в файловой системе
Синтаксис: df [опции]
Пример: df -h (все файловые системы с размером, занятым и свободным местом на диске)
Примечание: `-h` - красивое отображение (human readable, размерности в нормалльных величинах)

== 6 ==
Название: curl
Описание: выполнение http запросов из cmd
Синтаксис: curl [опция] <url>
Пример: curl http://127.0.0.1:8000
Примечание: важные флаги: `-X POST`- post запрос, `-I` - только заголовки, `-v` - подробный вывод запроса и ответа

== 7 ==
Название: ping
Описание: проверка доступности хоста в сети + проверка задержки
Синтаксис: ping [опции] <host>
Пример: ping github.com
Примечание: не работает с http:// | https:// - нужен домен/IP
полезные флаги: `-c <cnt>` - количество отправленных пакетов, `-i <delta>` - интервал отправки пакетов

== 8 ==
Название: find
Описание: поиск файла по имени / типу / размеру / дате 
Синтаксис: fing <path> [опции]
Пример: find . -name "*.py" (ищет .py в текущей директории(.) и всех ее поддиректориях)
Примечание: можно вместе с type для уточнения поиска

== 9 ==
Название: diff
Описание: построчное сравнение файлов
Синтаксис: diff [опции] <file1> <file2>
Пример: diff main.py plug.py
Примечание: полезные флаги: используется в системах контроля версий

== 10 ==
Название: history
Описание: отображение истории введенных команд 
Синтаксис: history [опции]
Пример: history 
Примечание: полезные флаги: `!!` - вывод последней команды, `!<n>` - выполнить команду под номером n из истории (чем больше номер тем недавнее была команда)
